### 簿財_1-1-2_01 会計の種類-1

### 会計の種類

```
会計
├── 非営利会計
└── 企業会計
    ├── 管理会計
    └── 財務会計
        ├── 非制度会計
        └── 制度会計
            ├── 税法会計
            ├── 金融商品取引法会計    ← 簿記論で扱う
            └── 会社法会計           ← 簿記論で扱う
```

企業会計：営利目的で経済活動を行う個人や団体，会社が行う会計
財務会計：企業会計のうち企業外部へ報告するための会計
制度会計：財務会計のうち，法の規制を受ける会計．法に準拠し，実務で実際に採用されている会計

### 簿財_1-1-2_03 制度会計

会社法の特徴：
- すべての会社に適用される法律（小さい会社でも適用できるようにしなければならない）
- 株主保護，債権者保護及び両者の利害調整が主たる目的

金商法の特徴：
- 多数の投資家や債権者が関与する企業に適用．


| 比較する項目     | 会社法           | 金融商品取引法         |
| ---------- | ------------- | --------------- |
| 法の規制を受ける企業 | すべての会社        | 上場会社等           |
| 規制の対象となる取引 | 会社の設立・解散・運営など | 有価証券や金融商品に関する取引 |
| 規制の趣旨      | 債権者保護         | 投資者保護           |

### 簿財_1-1-2_04 制度会計

会社法では，決算報告書を「計算書類」と呼ぶ．
金商法では，決算報告書を「財務諸表」と呼ぶ．
財務諸表は有価証券報告書に含まれ，有価証券報告書は内閣総理大臣に提出する．


| 比較する項目       | 会社法会計            | 金融商品取引法会計               |
| ------------ | ---------------- | ----------------------- |
| 準拠する法律       | 会社法              | 金融商品取引法                 |
| 実施する企業       | すべての会社           | 上場会社等                   |
| 決算報告書の名称（総称） | 計算書類             | 財務諸表                    |
| 決算報告書の提出等    | 株主へ提供<br>株主総会へ提出 | 有価証券報告書へ掲載<br>内閣総理大臣へ提出 |
会社法会計と金融商品取引法会計に実質的な会計は同じ
報告書の様式や表示・報告相手など，形式的な面だけ．
### 簿財_1-1-2_06 二元的な制度会計
二元的な情報開示
会社法に基づく計算書類，金商法に基づく財務諸表で二度手間．
会社法は法務省，金商法は金融庁と，それぞれの所感が異なるため，省庁間の議論，調整が進まない


### 簿財_1-1-3_01 出題範囲の違い
目的
- 税理士となるのに必要な学識
- 応用能力を有するかどうか
簿記論：期首・期中・期末の仕訳・試算表の作成・財務諸表の作成
財務諸表論：財務諸表の作成

総合問題の典型的な形式
与えられる資料：前T/B + 決算整理事項
作るもの：後T/B + B/S P/L

単位
- 簿記論：円，千円
- 財務諸表論：千円，百万円

作成する財務諸表論の違い
- 簿記論：略式の財務諸表 帳簿上の勘定科目で表示している
- 財務諸表論：厳密な財務諸表

簿記論で問われる時点
- 期首：仕訳・転記
- 期中：仕訳・転記・集計
- 期末：仕訳・転記・集計
公的なルールではなくても，様々な処理方法・計算方法も出題される
